# uth-mail-mcp

MCP server για το email του Πανεπιστημίου Θεσσαλίας (αυτό που βλέπεις στο
webmail.uth.gr). Συνδέεται με τον λογαριασμό σου και δίνει σε ένα πρόγραμμα AI
(Claude Desktop, Claude Code, Cursor κ.ά.) πρόσβαση στα:

- φάκελοι, με πόσα μηνύματα και πόσα αδιάβαστα έχει ο καθένας
- αναζήτηση μηνυμάτων με αποστολέα, θέμα, κείμενο, ημερομηνίες ή μόνο τα αδιάβαστα
- ανάγνωση μηνυμάτων, και των HTML
- κατέβασμα συνημμένων
- σήμανση ως αναγνωσμένο ή με σημαία, μετακίνηση σε φάκελο ή στον κάδο
- πρόχειρα, και απαντήσεις με το αρχικό μήνυμα από κάτω
- αποστολή προχείρου

Τίποτα δεν φεύγει χωρίς να το δεις: η αποστολή είναι δύο βήματα, πρώτα
πρόχειρο (το βλέπεις και στο webmail) και μετά αποστολή αυτού του προχείρου.
Οριστική διαγραφή δεν υπάρχει, τα μηνύματα πάνε μόνο στον κάδο (αν δεν
έχεις φάκελο κάδου, τον φτιάχνει).

Μιλάει απευθείας με τους servers αλληλογραφίας (IMAP και SMTP), όχι με τη
σελίδα του webmail.

## Εγκατάσταση

Χρειάζεται Python 3.10 ή νεότερο και το [uv](https://docs.astral.sh/uv/).

```
git clone https://github.com/fotispetrou/uth-mail-mcp
cd uth-mail-mcp
uv sync
```

## Στοιχεία σύνδεσης

Αποθήκευσε μία φορά το όνομα χρήστη και τον κωδικό σου στον κωδικοφύλακα του
συστήματος (στα Windows είναι το Credential Manager). Είναι τα ίδια με του
eClass. Το όνομα χρήστη είναι χωρίς το @uth.gr: στο webmail μπαίνεις και με
αυτό, αλλά οι servers αλληλογραφίας το θέλουν σκέτο (αν το γράψεις, το κόβει).

```
uv run uth-mail-mcp login
```

Σε ρωτάει και ένα όνομα για το «Από» των μηνυμάτων σου, αν θέλεις.
Εναλλακτικά βάλε τα στις μεταβλητές περιβάλλοντος `UTHMAIL_USERNAME`,
`UTHMAIL_PASSWORD` και `UTHMAIL_NAME`. Ο κωδικός δεν φεύγει από τον υπολογιστή
σου, πηγαίνει μόνο στους servers του πανεπιστημίου.

Δοκίμασε ότι όλα δουλεύουν (δεν στέλνει τίποτα):

```
uv run uth-mail-mcp check
```

## Άλλο τμήμα

Κάθε τμήμα έχει δικό του server για τα γραμματοκιβώτια, `mail.<τμήμα>.uth.gr`,
και εκεί είναι και οι διευθύνσεις φοιτητών `@uth.gr`. Το κεντρικό `mail.uth.gr`
δέχεται τον κωδικό αλλά δεν έχει το γραμματοκιβώτιο. Η προεπιλογή είναι του
Τμήματος Ψηφιακών Συστημάτων (`mail.ds.uth.gr`). Για άλλο τμήμα βάλε τον δικό
σου στη μεταβλητή `UTHMAIL_IMAP_HOST`, π.χ. `mail.ece.uth.gr`. Η αποστολή
γίνεται για όλους από το `smtp.uth.gr`.

Αν η διεύθυνσή σου δεν είναι `όνομαχρήστη@uth.gr`, βάλε τη σωστή στη
`UTHMAIL_ADDRESS`. Τα συνημμένα αποθηκεύονται στο `~/Downloads/uth-mail`,
ή όπου ορίσεις με τη `UTHMAIL_DOWNLOAD_DIR`.

## Σύνδεση με Claude Desktop ή Cursor

Στο αρχείο ρυθμίσεων (`claude_desktop_config.json` ή `mcp.json`) πρόσθεσε:

```json
{
  "mcpServers": {
    "uth-mail": {
      "command": "uv",
      "args": ["--directory", "C:/path/to/uth-mail-mcp", "run", "uth-mail-mcp"]
    }
  }
}
```

Βάλε τη διαδρομή όπου έκανες το clone. Αν δεν χρησιμοποίησες τον κωδικοφύλακα,
πρόσθεσε και `"env": {"UTHMAIL_USERNAME": "...", "UTHMAIL_PASSWORD": "..."}`.

Για Claude Code:

```
claude mcp add uth-mail -- uv --directory C:/path/to/uth-mail-mcp run uth-mail-mcp
```

Μετά ρωτάς απλά: «έχω αδιάβαστα από καθηγητές;», «βρες το email με το
πρόγραμμα της εξεταστικής και κατέβασε το συνημμένο», «γράψε μια απάντηση ότι
θα έρθω στο εργαστήριο την Πέμπτη».

## Εργαλεία

| εργαλείο | τι κάνει |
| --- | --- |
| `list_folders` | οι φάκελοι, με μηνύματα και αδιάβαστα |
| `search_messages` | αναζήτηση, τα νεότερα πρώτα |
| `get_message` | ένα μήνυμα ολόκληρο, με τη λίστα συνημμένων |
| `download_attachment` | αποθήκευση συνημμένου |
| `mark_messages` | αναγνωσμένο/αδιάβαστο, σημαία |
| `move_messages` | μετακίνηση σε άλλο φάκελο ή στον κάδο |
| `create_draft` | νέο μήνυμα ή απάντηση, ως πρόχειρο |
| `send_draft` | αποστολή ενός προχείρου |
| `whoami` | έλεγχος ότι η σύνδεση δουλεύει, και ο χώρος του γραμματοκιβωτίου |
